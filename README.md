# Мини-синхронизатор заявок

Сервис получает сырые заявки из `https://test.ooobs.ru/api/orders`, нормализует российские телефонные номера, удаляет невалидные записи и объединяет дубли. Для дублей выбирается максимальный `amount`, а при равенстве — наиболее поздний `created_at`.

## Запуск

```bash
npm test
npm start
```

Результат доступен на `http://localhost:3000/`.

## Идемпотентность и секреты

Обработка не имеет побочных эффектов: каждый GET заново строит детерминированный ответ из исходного массива, поэтому повторные запросы не создают дубли. Секреты сервису не нужны; если они появятся, они должны передаваться через переменные окружения платформы и не храниться в Git.
